# John Ghai Manyang — Professional Portfolio

Version 1 of the Manyang AI Portfolio Platform.

This responsive, accessible single-page portfolio presents John’s work across artificial intelligence, software development, data science, databases, and automation. It is intentionally built with HTML, CSS, and JavaScript for straightforward GitHub Pages deployment.

## Local preview

Open `index.html` directly, or run a small local web server from the repository root:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

- `index.html` — semantic page content and metadata
- `assets/styles.css` — responsive design system and layouts
- `assets/script.js` — navigation and small interface behaviours
- `assets/images/` — profile and project imagery
- `assets/documents/` — downloadable résumé
- `robots.txt` and `sitemap.xml` — search-engine discovery
